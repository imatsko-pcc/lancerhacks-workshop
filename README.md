1. Click **`attendees.md`** in the file list above
2. Click the **pencil icon** (top right of the file)
3. If GitHub asks, click **Fork this repository**
4. Add a line **under the heading** like this:

Your Name: one fun fact about you

5. Click **Commit changes** → **Propose changes**
6. Click **Create pull request** (twice)

That's it. 

## What just happened?

- **Fork:** your own copy of this repo
- **Commit:** a saved snapshot of your change
- **Pull request:** "please merge my change into the main repo"
- **Merge conflict:** two people changed the same lines, so a human picks what to keep
